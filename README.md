# FD GRÁFICA — V8.1 — CARROSSEL E CATÁLOGO ORGANIZADOS

Atualização de layout sobre a base V7.1. Esta versão reorganiza a Home, o catálogo e a vitrine de produtos.

## Ajustes desta versão
- Carrossel isolado por slide, com visibilidade e camadas corrigidas para evitar sobreposição de imagens.
- Catálogo movido para o topo da página, após o carrossel.
- Menu do catálogo separado por seções em negrito; itens em ordem alfabética dentro de cada seção.
- Seções “Escolha seu nicho” e “Artes e ideias para redes sociais” vêm antes dos produtos mais vendidos.
- Vitrine de produtos mais vendidos com cartões de visita, panfletos, banners e adesivos.
- Ao selecionar produto, a página não deve rolar automaticamente para o item.

As imagens do catálogo continuam ilustrativas/mockups e podem ser substituídas por imagens reais da FD Gráfica posteriormente.
